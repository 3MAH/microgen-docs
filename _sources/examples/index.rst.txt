.. _examples:

Examples
========

Each example is a standalone script: download it at the bottom of its page and
run it with ``python <name>.py``. Most of them are run at each documentation
build and the 3D scenes can be rotated in the *Interactive Scene* tab. Examples
that need the optional CAD backend say so (``pip install microgen[cad]``).

Spinodoids
----------

Stochastic, bicontinuous and exactly periodic microstructures generated from
Gaussian random fields.


.. raw:: html

  <div id='sg-tag-list' class='sphx-glr-tag-list'></div>


.. raw:: html

    <div class="sphx-glr-thumbnails">

.. thumbnail-parent-div-open

.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="Spinodoids mimic the bicontinuous microstructures of spinodal decomposition. A microgen.Spinodoid is a Gaussian random field: an FFT of white noise filtered by a Gaussian shell of radius k0 (the dominant wave number) and width bandwidth. The solid is the part where the field is above a threshold; giving density makes microgen find the threshold that matches this solid volume fraction.">
